# Support

Start with the [README](README.md) and the relevant skill under `skills/`.

- For a reproducible defect, use the [bug report template](https://github.com/Swellshinider/janitor/issues/new?template=bug_report.md).
- For a proposed capability or improvement, use the [feature request template](https://github.com/Swellshinider/janitor/issues/new?template=feature_request.md).
- For usage questions that are not bugs, open a clearly titled issue with the
  command, project context, and expected result.
- For security concerns, follow [SECURITY.md](SECURITY.md) instead of opening a
  public issue.
